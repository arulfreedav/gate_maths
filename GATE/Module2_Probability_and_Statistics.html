Core Theory

Bayes' Theorem, Expectation & Variance

Fundamental Rules
⚡ Bayes' Theorem & Total Probability

For mutually exclusive and exhaustive partition $B_1, B_2, \dots, B_k$:

$P(B_i | A) = \frac{P(A | B_i) P(B_i)}{\sum_{j=1}^k P(A | B_j) P(B_j)}$
  • Independent Events: $P(A \cap B) = P(A) P(B)$.
  • Mutually Exclusive: $P(A \cap B) = 0 \implies P(A \cup B) = P(A) + P(B)$.
📊 Expectation & Variance Properties
  • Linearity of Expectation: $E[aX + bY + c] = a E[X] + b E[Y] + c$ (Holds even if $X, Y$ are dependent!).
  • Variance: $\text{Var}(X) = E[X^2] - (E[X])^2$.
  • $\text{Var}(aX + b) = a^2 \text{Var}(X)$ (Additive constants don't affect spread).
  • $\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y) + 2\text{Cov}(X, Y)$. (If independent, $\text{Cov} = 0$).

Question 1: Diagnostic Bayes' Theorem

2 Marks MCQ
In a population, $1\%$ of people have a certain rare disease. A diagnostic test for the disease has a $95\%$ true positive rate (sensitivity) and a $5\%$ false positive rate (1 - specificity). If a randomly selected person tests positive, what is the probability that the person actually has the disease?
A0.95
B0.161
C0.500
D0.010
Beware of the base rate fallacy!
Correct Answer: Option B (~0.161 or 16.1%)
⚡ Base Rate Fallacy: Even with a 95% accurate test, because the disease is rare (1%), most positive tests will be false positives!

Bayes' Formula Calculation:

  1. Let $D$ = has disease, $D^c$ = healthy, $+$ = tests positive.
  2. Priors: $P(D) = 0.01$, $P(D^c) = 0.99$.
  3. Likelihoods: $P(+|D) = 0.95$, $P(+|D^c) = 0.05$.
  4. Total Probability of positive test: $$P(+) = P(+|D)P(D) + P(+|D^c)P(D^c) = (0.95)(0.01) + (0.05)(0.99) = 0.0095 + 0.0495 = 0.0590$$
  5. Posterior probability: $$P(D|+) = \frac{P(+|D)P(D)}{P(+)} = \frac{0.0095}{0.0590} = \frac{95}{590} \approx \mathbf{0.161}$$

Question 2: Poisson Arrival Process

2 Marks NAT
Packets arrive at a router following a Poisson process at an average rate of 2 packets per second. The probability that at least 1 packet arrives in a 2-second interval is ________ (round off to 2 decimal places, take $e \approx 2.718$).
Scale the arrival rate $\lambda$ by time $t = 2$:
Correct Answer: 0.98 (Acceptable range: 0.97 to 0.99)
⚡ Complement Rule: $P(X \ge 1) = 1 - P(X = 0)$!

Step-by-Step Derivation:

  1. Given arrival rate $\mu = 2$ packets/second. Over time $t = 2$ seconds, the parameter is: $$\lambda = \mu \times t = 2 \times 2 = 4$$
  2. The number of arrivals $X \sim \text{Poisson}(\lambda = 4)$. $$P(X = k) = \frac{e^{-4} \cdot 4^k}{k!}$$
  3. Probability of 0 packets: $$P(X = 0) = \frac{e^{-4} \cdot 4^0}{0!} = e^{-4} \approx 0.0183$$
  4. Probability of at least 1 packet: $$P(X \ge 1) = 1 - P(X = 0) = 1 - e^{-4} = 1 - 0.0183 = \mathbf{0.9817} \approx \mathbf{0.98}$$

Question 3: Covariance & Joint Expectation

2 Marks NAT
Let $X$ and $Y$ be random variables with $\text{Var}(X) = 9$, $\text{Var}(Y) = 16$, and correlation coefficient $\rho(X, Y) = 0.5$. The value of $\text{Var}(2X - 3Y)$ is ________.
Expand the variance of linear combination:
Correct Answer: 108
⚡ Master Identity: $\text{Var}(aX + bY) = a^2 \text{Var}(X) + b^2 \text{Var}(Y) + 2ab \text{Cov}(X, Y)$.

Step-by-Step Solution:

  1. Standard deviations: $\sigma_X = \sqrt{9} = 3$, $\sigma_Y = \sqrt{16} = 4$.
  2. Covariance formula: $$\text{Cov}(X, Y) = \rho(X, Y) \cdot \sigma_X \cdot \sigma_Y = (0.5)(3)(4) = 6$$
  3. Now expand $\text{Var}(2X - 3Y)$ (here $a = 2$, $b = -3$): $$\text{Var}(2X - 3Y) = 2^2 \text{Var}(X) + (-3)^2 \text{Var}(Y) + 2(2)(-3)\text{Cov}(X, Y)$$ $$= 4(9) + 9(16) - 12(6)$$ $$= 36 + 144 - 72 = 180 - 72 = \mathbf{108}$$

Question 4: Standard Normal Symmetry

1 Mark MCQ
Let $X$ be a normally distributed random variable with mean $\mu = 10$ and variance $\sigma^2 = 4$. If $\Phi(z)$ denotes the cumulative distribution function of the standard normal distribution $\mathcal{N}(0, 1)$, then $P(8 \le X \le 12)$ is equal to:
A$2\Phi(1) - 1$
B$2\Phi(1)$
C$\Phi(1) - \Phi(-1)$
DBoth A and C
Convert to standard normal $Z = \frac{X - \mu}{\sigma}$:
Correct Answer: Option D (Both A and C are equivalent!)

Standardization:

  • Standard deviation $\sigma = \sqrt{4} = 2$.
  • For $X = 8$: $Z_1 = \frac{8 - 10}{2} = -1$.
  • For $X = 12$: $Z_2 = \frac{12 - 10}{2} = +1$.
  • Therefore: $P(8 \le X \le 12) = P(-1 \le Z \le 1) = \Phi(1) - \Phi(-1)$.
  • By symmetry of standard normal distribution, $\Phi(-1) = 1 - \Phi(1)$.
  • Substituting: $\Phi(1) - (1 - \Phi(1)) = 2\Phi(1) - 1 \approx 0.6826$ (the famous 68% rule!).

Question 5: Central Limit Theorem (CLT) & Margin of Error

2 Marks MCQ
A random sample of size $n = 64$ is drawn from a population with unknown mean $\mu$ and known standard deviation $\sigma = 16$. According to the Central Limit Theorem, the distribution of the sample mean $\bar{X}$ has a standard error of:
A16
B4
C2
D0.25
Formula for standard error of the mean:
Correct Answer: Option C (Standard Error = 2)
⚡ Standard Error Formula: $SE(\bar{X}) = \frac{\sigma}{\sqrt{n}}$.

Calculation:

$SE(\bar{X}) = \frac{\sigma}{\sqrt{n}} = \frac{16}{\sqrt{64}} = \frac{16}{8} = \mathbf{2}$

Core CLT Takeaways for GATE DA:

  • As $n \to \infty$, $\bar{X} \xrightarrow{d} \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right)$, regardless of whether the original population is normal!
  • A $95\%$ Confidence Interval for $\mu$ is: $\bar{x} \pm z_{0.025} \frac{\sigma}{\sqrt{n}} = \bar{x} \pm 1.96(2) = \bar{x} \pm 3.92$.

Question 6: Hypothesis Testing Errors (MSQ)

1 Mark MSQ
In statistical hypothesis testing, which of the following statements is/are CORRECT?
AType I error ($\alpha$) is rejecting the null hypothesis $H_0$ when $H_0$ is true.
BType II error ($\beta$) is failing to reject $H_0$ when $H_0$ is false.
CThe Power of a test is defined as $1 - \beta$.
DIf the $p$-value is less than the significance level $\alpha$, we fail to reject $H_0$.
Review the decision rule for p-value:
Correct Options: A, B, C
⚡ Exam Mnemonic: "If $p$ is low, $H_0$ must go!" (i.e., if $p \le \alpha$, REJECT $H_0$).
  • Option A is TRUE: $\alpha = P(\text{Reject } H_0 \mid H_0 \text{ is true})$ (False Positive).
  • Option B is TRUE: $\beta = P(\text{Fail to reject } H_0 \mid H_0 \text{ is false})$ (False Negative).
  • Option C is TRUE: Power of test = $1 - \beta = P(\text{Reject } H_0 \mid H_0 \text{ is false})$.
  • Option D is FALSE: When $p\text{-value} < \alpha$, we REJECT $H_0$, not fail to reject it!

Question 7: Memoryless Property of Exponential Distribution

1 Mark MCQ
The lifetime of an electronic component is exponentially distributed with a mean of 100 hours. If the component has already survived for 200 hours, what is the probability that it survives for at least another 100 hours?
A$e^{-3}$
B$e^{-1}$
C$e^{-2}$
D$1 - e^{-1}$
Memoryless property removes past survival time:
Correct Answer: Option B ($e^{-1}$)
⚡ 5-Second Memoryless Shortcut: $P(X > s + t \mid X > s) = P(X > t)$ regardless of $s$!

Formal Derivation:

  1. Mean $\mu = \frac{1}{\lambda} = 100 \implies \lambda = 0.01$.
  2. For any Exponential distribution, survival function $P(X > t) = e^{-\lambda t}$.
  3. By memoryless property: $$P(X > 200 + 100 \mid X > 200) = P(X > 100) = e^{-\lambda(100)} = e^{-(0.01)(100)} = \mathbf{e^{-1}}$$

Question 8: Expectation of a Continuous Random Variable

2 Marks NAT
A continuous random variable $X$ has the probability density function (PDF): $$f(x) = \begin{cases} c x^2, & 0 \le x \le 3 \\ 0, & \text{otherwise} \end{cases}$$ The expected value $E[X]$ is ________ (in decimal, exact).
First find constant $c$ such that $\int f(x)dx = 1$:
Correct Answer: 2.25

Step 1: Determine Constant $c$:

$\int_0^3 c x^2 dx = 1 \implies c \left[\frac{x^3}{3}\right]_0^3 = c \left(\frac{27}{3}\right) = 9c = 1 \implies c = \frac{1}{9}$

Step 2: Calculate Expectation $E[X] = \int x f(x) dx$:

$E[X] = \int_0^3 x \left(\frac{1}{9} x^2\right) dx = \frac{1}{9} \int_0^3 x^3 dx = \frac{1}{9} \left[\frac{x^4}{4}\right]_0^3 = \frac{1}{9} \left(\frac{81}{4}\right) = \frac{9}{4} = \mathbf{2.25}$

Question 9: Conditional Expectation $E[X \mid Y=y]$

2 Marks NAT
Let $(X, Y)$ have the joint PMF given by the table below:
$X \setminus Y$$Y = 1$$Y = 2$
$X = 1$0.10.2
$X = 2$0.30.4
The conditional expectation $E[X \mid Y = 2]$ is ________.
First find marginal $P(Y=2)$, then conditional distribution $P(X=x \mid Y=2)$:
Correct Answer: 1.667 (or 5/3)

Step-by-Step Calculation:

  1. Marginal probability $P(Y = 2) = 0.2 + 0.4 = 0.6$.
  2. Conditional probabilities for $X$ given $Y = 2$: $$P(X = 1 \mid Y = 2) = \frac{P(X=1, Y=2)}{P(Y=2)} = \frac{0.2}{0.6} = \frac{1}{3}$$ $$P(X = 2 \mid Y = 2) = \frac{P(X=2, Y=2)}{P(Y=2)} = \frac{0.4}{0.6} = \frac{2}{3}$$
  3. Conditional expectation: $$E[X \mid Y = 2] = 1 \left(\frac{1}{3}\right) + 2 \left(\frac{2}{3}\right) = \frac{1}{3} + \frac{4}{3} = \frac{5}{3} \approx \mathbf{1.67}$$

Question 10: Balls into Bins Probability

1 Mark MCQ
Three identical balls are randomly placed into 3 distinct bins. Each ball has an equal probability of landing in any of the bins. What is the probability that no bin is empty?
A$1/3$
B$2/9$
C$6/27 = 2/9$
D$1/9$
Total outcomes when balls are placed independently:
Correct Answer: Option B / C (2/9 or 6/27)

Derivation:

  • Each ball independently chooses one of the 3 bins. Total number of outcomes $= 3^3 = 27$.
  • For "no bin is empty", each bin must receive exactly 1 ball.
  • The number of ways to assign 3 distinct balls to 3 distinct bins with 1 per bin is $3! = 6$.
  • Probability $= \frac{6}{27} = \mathbf{\frac{2}{9}} \approx 0.222$.
