Complete Linear Algebra Theory & Formulas

Comprehensive reference covering every definition, theorem, formula, and edge-case tested in GATE CS and GATE DA.

1. Matrices & Special Matrix Types

Let $A \in \mathbb{R}^{m \times n}$. Standard definitions and properties:

  • Square Matrix: $m = n$.
  • Symmetric Matrix: $A^T = A$ ($a_{ij} = a_{ji}$). Always square with strictly real eigenvalues.
  • Skew-Symmetric Matrix: $A^T = -A$ ($a_{ij} = -a_{ji}$). Diagonal entries are identically 0 ($a_{ii} = 0$). For odd $n$, $\det(A) = 0$.
  • Orthogonal Matrix: $A^T A = A A^T = I \iff A^{-1} = A^T$. $\det(A) = \pm 1$. Columns form an orthonormal basis.
  • Trace: $\text{Trace}(A) = \sum_{i=1}^n a_{ii} = \sum_{i=1}^n \lambda_i$. Cyclic invariance: $\text{Trace}(AB) = \text{Trace}(BA)$.

2. Determinants & Shortcut Theorems

  • Scalar rule: $\det(k A) = k^n \det(A)$ for an $n \times n$ matrix $A$.
  • Product rule: $\det(AB) = \det(A) \det(B) = \det(BA)$ (holds even if $AB \neq BA$).
  • Inverse rule: $\det(A^{-1}) = \frac{1}{\det(A)}$.
  • Block Triangular: $\det \begin{pmatrix} A & C \\ 0 & B \end{pmatrix} = \det(A) \cdot \det(B)$.
  • Adjoint formulas:
    $|\text{adj}(A)| = |A|^{n-1} \qquad |\text{adj}(\text{adj}(A))| = |A|^{(n-1)^2} \qquad \text{adj}(\text{adj}(A)) = |A|^{n-2} A$

3. Matrix Rank & The Rank-Nullity Theorem

  • Row Rank = Column Rank = $\text{Rank}(A) \le \min(m, n)$.
  • Rank-Nullity Theorem:
    $\text{Rank}(A) + \text{Nullity}(A) = n \quad (\text{number of columns})$
  • Outer Product: For non-zero vectors $u \in \mathbb{R}^m, v \in \mathbb{R}^n$, $\text{Rank}(u v^T) = 1$ and $\text{Nullity} = n - 1$.
  • Sylvester's Inequality: $\text{Rank}(AB) \ge \text{Rank}(A) + \text{Rank}(B) - n$.
  • Gram Matrix: $\text{Rank}(A^T A) = \text{Rank}(A A^T) = \text{Rank}(A)$, and $\text{Null}(A^T A) = \text{Null}(A)$.

5. Eigenvalues, Cayley-Hamilton & Diagonalization

  • Characteristic Equation: $\det(A - \lambda I) = 0$.
  • Sum of Eigenvalues: $\sum \lambda_i = \text{Trace}(A)$.
  • Product of Eigenvalues: $\prod \lambda_i = \det(A)$.
  • Cayley-Hamilton: Every matrix satisfies $p(A) = 0$. Used for calculating inverse $A^{-1}$ and high powers $A^m$.
  • Spectral Theorem: Any real symmetric matrix ($A^T = A$) has strictly real eigenvalues and can be orthogonally diagonalized: $A = Q \Lambda Q^T$ with $Q^T Q = I$.

6. SVD (Singular Value Decomposition) & Projections (GATE DA Core)

  • SVD Formula: $A = U \Sigma V^T$ where $U, V$ are orthogonal matrices and $\Sigma$ is diagonal with singular values $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0$.
  • Singular Value Identity: $\sigma_i = \sqrt{\lambda_i(A^T A)}$. Singular values are ALWAYS real and non-negative ($\sigma_i \ge 0$).
  • Matrix Norms:
    • Spectral Norm: $\|A\|_2 = \sigma_{\max} = \sigma_1$
    • Frobenius Norm: $\|A\|_F = \sqrt{\sum \sigma_i^2} = \sqrt{\text{Trace}(A^T A)}$
    • Condition Number: $\kappa_2(A) = \frac{\sigma_{\max}}{\sigma_{\min}}$
  • Orthogonal Projection Matrix: $P = A(A^T A)^{-1} A^T$ (satisfies $P^2 = P$ and $P^T = P$).
  • Quadratic Forms: $Q(x) = x^T A x$. Positive Definite $\iff$ all $\lambda_i > 0 \iff$ all leading principal minors $> 0$.

7. GATE Trap Alert Summary

  • $\det(A + B) \neq \det(A) + \det(B)$ in general!
  • $\text{Rank}(A) + \text{Nullity}(A) = n$ (columns), NEVER $m$!
  • Invertible does NOT mean diagonalizable (e.g. defective triangular matrices).
  • Singular values can NEVER be negative, even if eigenvalues are negative.
  • $Ax = 0$ is NEVER inconsistent; it always has the trivial solution $x = 0$.
